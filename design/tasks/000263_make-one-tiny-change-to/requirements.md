# Requirements

## User Story

As a developer, I want to make a small change to the docs repo and push it so I can test the PR flow end-to-end.

## Acceptance Criteria

- A minor, non-breaking edit is made to a file in the `docs` repo (e.g. a whitespace or wording tweak in `README.md`)
- The change is committed and pushed to a new branch
- A pull request is opened for review
